# RankBrum Hermes Blueprint Examples

This directory contains example implementations and templates that demonstrate how to use the RankBrum Hermes system.

## Contents

### Templates
- `project-brief-template.md` - Template for creating project briefs
- `technical-request-template.md` - Template for technical requests
- `qa-report-template.md` - Template for QA reports

### Example Workflows
- `simple-landing-page-example.md` - Example of a simple landing page project
- `saas-mvp-example.md` - Example of a SaaS MVP project
- `chatbot-example.md` - Example of a chatbot implementation

### Code Examples
- `sample-frontend-component.jsx` - Sample React component
- `sample-backend-endpoint.py` - Sample Python backend endpoint
- `sample-qa-test.js` - Sample QA test script

## Usage

These examples are for educational purposes only and should be adapted to your specific needs.
Always follow the governance principles outlined in the blueprint when implementing projects.
